# 🚀 Quick Guide: Using LLaVA Models (Free Alternative)

## Why Switch to LLaVA?
- ✅ **Completely Free** - No rate limits or quotas
- ✅ **No Billing Required** - Just need a Hugging Face account
- ✅ **Multiple Model Sizes** - 7B, 13B parameter options
- ✅ **Multimodal Capabilities** - Can analyze images and text

## 🔑 Setup Steps

### 1. Get Hugging Face Token
1. Visit [Hugging Face](https://huggingface.co/)
2. Sign up or log in
3. Go to **Settings** → **Access Tokens**
4. Click **New token**
5. Give it a name (e.g., "AI Vision Explorer")
6. Select **Read** role
7. Click **Generate token**
8. **Copy the token immediately** (you won't see it again)

### 2. Use in the App
1. Open the AI Vision Explorer app
2. In the sidebar, select **"Gemma"** instead of "Gemini"
3. Choose a model:
   - **LLaVA 1.5 7B**: Fast, balanced performance (recommended)
   - **LLaVA 1.6 Mistral 7B**: Enhanced capabilities
   - **LLaVA v1.5 7B**: Original model
4. Paste your Hugging Face token in the API Key field
5. Upload an image and ask questions!

## 🔧 Troubleshooting

### If you get "Model not found" error:
- Check that you selected the correct model name
- Ensure your Hugging Face token is valid
- Try a different LLaVA model

### If analysis is slow:
- Use smaller models (7B instead of larger variants)
- Reduce image size before uploading
- Check your internet connection

### If you get API errors:
- Verify your token has 'read' permissions
- Check that the model name is exactly as shown
- Try refreshing the page and re-entering your token
